# vernier documentation

Documentation follows the [Diátaxis](https://diataxis.fr/) framework, with one
top-level addition for migration guides (ADR-0027):

- **tutorials/** — Learning-oriented, step-by-step lessons for new users.
- **migrate/** — Task-oriented migration guides for users switching from pycocotools, lvis-api, panopticapi, or other evaluators.
- **how-to/** — Task-oriented guides for users who already know what they want.
- **reference/** — Information-oriented, exhaustive API and CLI specs.
- **explanation/** — Understanding-oriented background, theory, and architecture.
- **adr/** — Architecture Decision Records: the immutable record of *why* we chose what we chose.
- **engineering/** — Internal standards (code style, contribution constraints, release process).
