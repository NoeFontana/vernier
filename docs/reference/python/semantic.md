# `vernier.semantic`

Semantic-segmentation evaluation (mIoU + per-class confusion matrix).
`Evaluator` + `evaluate(...)` mirror the instance API; the
`*_IGNORE_LABEL` / `*_N_CLASSES` constants are convenience defaults for
common public datasets.
