# `vernier.instance.obb`

Oriented-box diagnostics (ADR-0063). None of this is evaluation — it is
the set of questions that come up *around* an oriented-box evaluation,
where the answers are otherwise expensive to get wrong.

The kernels themselves are
[`RotatedBox`](instance.md#vernier.instance.RotatedBox) and
[`Quad`](instance.md#vernier.instance.Quad), used through the ordinary
`Evaluator`. See
[Oriented-box conventions](../../explanation/obb-conventions.md) for the
background.
