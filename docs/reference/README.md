# Reference

Exhaustive technical reference: Python API, Rust API, CLI flags, JSON
schemas. Generated where possible; hand-curated where not.

## Python API

Generated by [mkdocstrings](https://mkdocstrings.github.io/) from the
public `__all__` lists and in-source docstrings — one page per
top-level module.

- [`vernier`](python/vernier.md) — top-level utilities (`Frequency`,
  `ParityMode`, `COCOeval`, `version`).
- [`vernier.instance`](python/instance.md) — bbox / segm / boundary /
  keypoints evaluation.
- [`vernier.panoptic`](python/panoptic.md) — panoptic-quality
  evaluation.
- [`vernier.semantic`](python/semantic.md) — semantic-segmentation
  evaluation.
- [`vernier.adapters`](python/adapters.md) — drop-in shims (currently
  the pycocotools `COCOeval` adapter).

A per-crate Rust API index lands in a follow-up; until then the canonical
Rust reference is [docs.rs](https://docs.rs/vernier-core).
