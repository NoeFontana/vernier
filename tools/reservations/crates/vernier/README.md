# vernier (name reservation)

This is a placeholder v0.0.0 release that claims the `vernier` name on
crates.io. It contains no code and exposes no public API.

The real `vernier` crate — a high-performance, parity-preserving
COCO-style evaluator — will land at v0.0.1 or later. The project ships
under 0.0.x patches until the core and extended feature set is
complete; moving to 0.1.0+ is a deliberate later decision. Track
progress at <https://github.com/NoeFontana/vernier>.
